📄 RAG Production App – PDF Question Answering System

A production-grade Retrieval-Augmented Generation (RAG) application that allows users to upload PDFs and ask natural language questions over their content.

Built using FastAPI, Inngest, Qdrant (Dockerized), Gemini (OpenAI-compatible API), LlamaIndex, and an interactive Streamlit UI.

🚀 Features

📤 Upload PDFs and ingest them asynchronously

✂️ Automatic document chunking using LlamaIndex

🧠 Semantic embeddings using Gemini (OpenAI-compatible API)

🗄️ Vector storage and similarity search using Qdrant (Docker)

🤖 Context-aware answers generated by an LLM

🔄 Event-driven orchestration with Inngest

📊 Full observability of ingestion and query pipelines

🖥️ Interactive Streamlit UI for end users

⚙️ Setup Instructions


1️⃣ Clone the repository
git clone https://github.com/your-username/rag-production-app.git
cd rag-production-app

2️⃣ Create and activate virtual environment
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate

3️⃣ Install dependencies
pip install -r requirements.txt

🐳 Run Qdrant using Docker (Required)

Qdrant runs as a Docker container to simulate a production-ready vector database.

docker run -d \
  -p 6333:6333 \
  -p 6334:6334 \
  --name qdrant \
  qdrant/qdrant


Verify Qdrant is running:

http://localhost:6333

🔐 Environment Variables

Create a .env file (this file is gitignored):

GEMINI_API_KEY=your_api_key_here

▶️ Running the Application
Start Inngest Dev Server
npx inngest-cli@latest dev

Start FastAPI Server
uvicorn main:app --reload

Start Streamlit UI
streamlit run streamlit_app.py

📥 PDF Ingestion Flow

User uploads a PDF via the Streamlit UI

An ingestion event is sent to Inngest

The PDF is:

Loaded and chunked

Embedded using Gemini

Stored in Qdrant with metadata

Each step is fully traceable in the Inngest dashboard.

🔎 Querying the PDFs

Users can ask natural language questions about the uploaded documents.

🧪 Example Queries

What is this document about?

Summarize the key points of the PDF

List the main topics discussed

What technologies or tools are mentioned?

Extract important dates or figures from the document
